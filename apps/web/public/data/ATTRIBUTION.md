# Data attribution

Files in this directory are generated by `tools/openings-data` (`pnpm --filter @chess/openings-data build`).

| Data | Source | License |
|---|---|---|
| Opening names, ECO codes, move lines (canonical) | [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings) | CC0 1.0 (public domain) |
| Extra opening names / aliases / lines | [JeffML/eco.json](https://github.com/JeffML/eco.json) | MIT — Copyright (c) Jeff Lowery and contributors |
| Opening notes (`notes.*.json`) | [Wikibooks — Chess Opening Theory](https://en.wikibooks.org/wiki/Chess_Opening_Theory) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| Popularity / W-D-L statistics | [Lichess Opening Explorer](https://lichess.org/analysis#explorer) (lichess + masters databases) | Lichess data, used per the Lichess API terms |

Notes are excerpts of Wikibooks pages, shortened and with reference sections removed. Each note
records its source page URL (`url`) and must be shown with attribution to Wikibooks and a link to
the page. The notes files are distributed under CC BY-SA 4.0.
